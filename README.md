# Form Warfare

#### Este juego es 2D y basicamente es una guerra de formas geometricas y tienes que ir eliminando el maximo de formas posible. Para poder jugar a este juego se tiene que descargar toda la carpeta dependiendo del sistema operativo.

# Informacion Importante
TAMBIEN ESTAN LOS PROYECTOS TANTO BUILDEADOS EN EL REPOSITORIO UNITY POR SI SE QUIERE PROBAR EL JUEGO.
DOY TOTAL LIBERTAD PARA HACERLO PERO ESTARIA BIEN INTENTAR CONTACTAR CONMIGO PARA PODER VER LOS CAMBIOS.
